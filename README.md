# Progetto Web Dev

React + TypeScript + Vite + Tailwind CSS v4 + PWA.

## Comandi

```bash
npm install
npm run dev
```

Build di produzione (genera anche service worker e manifest PWA):

```bash
npm run build
npm run preview
```

La PWA è installabile da `preview` (o da un host HTTPS). In `dev` il service worker non è attivo di default.
